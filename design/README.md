## What we took from Detroit: Become Human

Kept, but toned down so pages stay fast and readable:

| In the game | On the site |
| --- | --- |
| Bright, sterile white-blue world, one steel-blue accent | Light theme by default (`#EEF2F5` ground, `#1D5A91` accent). Dark theme via the toggle |
| Blurred bright room behind the menus (the Chloe screens) | `public/bg/room-*.webp`, generated by `make-background.mjs`, loaded after the page, slow "breathing" drift + scroll parallax |
| Large translucent triangles | One SVG of soft facets over the room, low contrast, drifting and parallaxing at a different speed for depth |
| Corner-bracket selection frame (`⌜ ⌟`) | Hover/focus state of cards, buttons, sub-page links, previous/next; always on callouts (one corner) |
| Selected blue bar with a glow spilling below | Primary buttons and the YouTube play button: navy→blue gradient, soft blue glow that slowly breathes, a sheen every few seconds |
| Uppercase tracked labels, mixed weights ("AKIF **KAZI**") | Montserrat (closest free match to the game's Gotham-like UI face) for display text only; body stays system UI |
| Loading screen: bar + "34%" bottom-left | Reading progress at the bottom of the left rail on desktop (a thin top bar on smaller screens) |
| Settings list: label left, value right, hairlines | Facts strip on home, project meta, `Key:: value` fact lists |

Left out on purpose: cut/sliced imagery, glitch effects, hover effects on things that aren't clickable (images), decorative text that says nothing (numbering, counts, "end of file").

## Layout

- Desktop (≥1200px) articles: sticky left rail (home link, chapters, progress) and right rail (site nav, theme, this page's role/year/tags, previous/next). The top bar and bottom pager hide there.
- Smaller screens: top bar, thin progress bar, previous/next at the end of the page.

## Rules

- Sharp corners everywhere. No `border-radius`.
- Icons: [Material Symbols Sharp](https://fonts.google.com/icons), weight 200, from `build/icons/` (see `build/icons.mjs` to add one). One set only. Arrows must point the way the link goes.
- Hover effects only under `@media (hover:hover) and (pointer:fine)`, and only on things you can click; touch gets `:active` feedback instead.
- Motion only under `prefers-reduced-motion: no-preference`. The background image is skipped on data-saver.
- Transparent images (drawn for Notion's dark theme) sit on a dark backdrop (`--media`) in both themes. Detected automatically at build time.
- No text that repeats what's already on screen.
